# IEEE upstream assets

The original archives are preserved byte-for-byte in this directory. They were
present in the working tree when this implementation began; their download
history was not included, so the exact original download URLs cannot be
independently confirmed. Upstream project references are the IEEE conference
template portal (https://template-selector.ieee.org/) and the IEEEtran BibTeX
style project (https://ctan.org/pkg/ieeetran).

| Archive | Internal version / contents | SHA-256 |
|---|---|---|
| `conference-latex-template.zip` | IEEE conference template dated 2024-06-28; IEEEtran class identifies itself internally | `516252d9ac6e974af3a1d9aa72f97ecc462b9a47556225019fb0adef69bba78a` |
| `IEEEtranBST2.zip` | IEEEtran BibTeX styles dated 2007-01-11 | `c77fec4cb5e0f3a8e4ce3ad36580341f5acae97d7131918095c6ca891c5f805c` |

Extracted runtime assets are limited to `IEEEtran.cls` and the default
`IEEEtran.bst`; `IEEEtranS.bst` is intentionally not selected. The upstream
example source, HOWTOs, and README are retained for attribution/reference.
Build residue such as `.synctex.gz` is not part of the runtime assets or
submission bundle. Consult the notices included in the archives and the
upstream project terms before redistribution. No additional license grant is
asserted here.
